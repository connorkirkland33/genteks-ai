## What Is This?

GenTeks AI is an internal AI platform that replaces the commercial AI subscription the team was previously using. It runs on a dedicated server and is accessible from any device via browser — no installation required.

The platform gives the team access to an AI assistant that can:
- Answer questions instantly (Chat mode)
- Research topics and write documents autonomously (Task mode)
- Generate Word, Excel, and PowerPoint files
- Analyze images
- Remember information across sessions

## How To Use It

### Chat Mode (⚡)
Best for: quick questions, email drafts, troubleshooting guidance, client communications.

1. Make sure **⚡ Chat** is selected in the mode bar
2. Type your question and press Enter
3. Response appears in seconds

### Task Mode (⚙)
Best for: research reports, document generation, web searches, complex multi-step tasks.

1. Switch to **⚙ Task** mode
2. Describe what you want in detail
3. Watch the step log as the agent works in real time
4. Response and any generated files appear when complete

**Example Task prompts:**
- `Research cybersecurity best practices for SMBs and write a report`
- `Create an Excel spreadsheet with a quarterly IT budget template`
- `Write a professional email to a client explaining scheduled maintenance`
- `Search the web for the latest ransomware threats and summarize them`

### Files Panel
All files generated by Task mode appear here. You can download or delete them.

### Memory Panel
Search the AI's stored knowledge from past interactions.

### Dashboard Quick Prompt
Run a quick Chat or Task query directly from the Dashboard without switching panels.

## API Key

The platform uses GenTeks' Anthropic API key stored in `config.toml`. This key controls billing and usage. Keep it private.

**To rotate the API key:**
1. Go to console.anthropic.com
2. Generate a new key
3. SSH into the server
4. Run: `nano /home/genteks/openmanus/ManusProjects/config/config.toml`
5. Update both `api_key` values under `[llm]` and `[llm.vision]`
6. Run: `sudo systemctl restart genteks-ai`

## Troubleshooting

**Platform not loading in browser:**
- SSH into server and run: `sudo systemctl status genteks-ai`
- If it shows failed: `sudo systemctl restart genteks-ai`
- If it won't start: `sudo journalctl -u genteks-ai -n 50 --no-pager`

**Task mode returning errors:**
- Check logs: `sudo journalctl -u genteks-ai -f`
- Try restarting: `sudo systemctl restart genteks-ai`

**Platform is slow:**
- Task mode can take 1-5 minutes for complex tasks — this is normal
- Chat mode should respond in 2-5 seconds — if slower, check server load

**Server needs a reboot:**
- The service will automatically restart after reboot — no manual action needed
